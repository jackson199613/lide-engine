# 动态文章写作规范（定时任务使用）

## 发布流程
1. `python3 tools/publish.py next` 取下一个待写关键词（按 n 顺序，`news/<slug>.html` 不存在即未发布）。返回 null 表示 100 个已写完：不发布，直接结束。
2. 读 `llms.txt`、`method.html`、`solutions.html`、`pricing.html` 了解立德引擎的定位、三项核心能力与服务档位，保持口径一致。
3. 用网络搜索核实文中要用的任何数据、平台功能或标准；只写能核实的内容。
4. 把文章写成 JSON（字段见 `tools/publish.py` 顶部说明），保存到仓库外的临时目录，运行 `python3 tools/publish.py publish <文件>`。
5. 检查生成的页面能正常解析（标签闭合、链接以 `/` 开头），然后提交并推送到 main，Netlify 自动上线。

## 内容要求
- 中文，1800–2800 字；读者是出口工厂老板、外贸经理、市场负责人。
- 标题：可在 keywords.tsv 建议标题基础上优化，含主关键词，≤ 32 字，可带「（2026）」或数字。不得与 news.html 已有标题重复或高度相似。
- 开头第一段直接回答标题的问题（AI 引用最常截取首段），主关键词出现在首句。
- 结构：导语 → 「要点速览」（`<div class="post-src"><strong>要点速览</strong><ul>…</ul></div>`，4–5 条）→ 4–7 个 `<h2>` 小节（用买家/老板会问的问题作小标题）→ 至少 1 个 `<div class="table-wrap"><table>…</table></div>` 对比表或清单表 → 结尾一段自然引导到免费 AI 能见度诊断或相关页面。
- FAQ 3–5 条，用真实问法，答案首句给结论。
- 站内链接 2–4 个，只链接真实存在的页面：/method.html、/pipeline.html、/pricing.html、/solutions.html、/how-to.html、/faq.html、/checklist.html、/contact.html，或 /news/ 下已发布的文章。
- 行业类文章写出该行业买家真正关心的参数、认证、标准与采购问法，避免空话。

## 真实性红线
- 不编造统计数字、调研结论、客户名称、客户案例或引语。数字必须来自可核实来源，并在 `sources` 里给出链接；拿不准就不用数字。
- 不承诺排名或「保证被 AI 推荐」。立德引擎官网公开的量化口径（提及率提升 30%–70% 等）只能原样引用，并注明为立德引擎服务口径。
- 不贬低具名竞争对手；不写医疗功效、合规结论等需要资质的判断。
- 引用外部文字每处不超过 15 字，其余用自己的话转述。
